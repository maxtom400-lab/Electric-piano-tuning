# ESP32-C3 Piano Motor 固件

这版固件用于 `ESP32-C3 SuperMini + 双路直流电机驱动板 + 两个限位开关`。

## Arduino IDE 设置

建议先用这些设置：

- Board：`ESP32C3 Dev Module`
- USB CDC On Boot：`Enabled`
- 如果看不到 COM 口，按住 `BOOT` 再插 USB，或 `按住 BOOT → 按一下 RESET → 松开 RESET → 松开 BOOT`
- 上传成功后，按一下 `RESET` 才会运行
- 串口监视器：`115200`

## 接线

先用这四个 GPIO：

| ESP32-C3 | 连接 |
|---|---|
| GPIO4 | 电机驱动 IN1 |
| GPIO5 | 电机驱动 IN2 |
| GPIO6 | 低音/左限位开关，另一端接 GND |
| GPIO7 | 高音/右限位开关，另一端接 GND |
| GND | 电机驱动 GND / 降压模块 GND / 12V 负极 |

限位开关程序使用 `INPUT_PULLUP`：

- 没触发：HIGH
- 触发：LOW

## 供电

推荐：

```text
12V 电源输入
├── 电机驱动板电机电源
└── 12V 转 5V 降压模块
      └── ESP32-C3 USB-C 或 5V/VBUS

12V负极 / 降压GND / ESP32 GND / 电机驱动GND 必须共地
```

不要把 12V 接到 ESP32 GPIO。

## BLE

ESP32 会广播成：

```text
troy high school
```

BLE UUID：

```text
Service: 0000FFE0-0000-1000-8000-00805F9B34FB
Notify:  0000FFE1-0000-1000-8000-00805F9B34FB
Write:   0000FFE2-0000-1000-8000-00805F9B34FB
```

限位通知：

| 事件 | 通知 |
|---|---|
| 低音/左限位触发 | `A1 01 01` |
| 低音/左限位释放 | `A1 01 02` |
| 高音/右限位触发 | `A1 02 01` |
| 高音/右限位释放 | `A1 02 02` |

## 支持命令

兼容 APP 的二进制命令：

| 动作 | 命令 |
|---|---|
| 查询安全协议能力 | `A1F100`，响应 `SAFE_V2`（含棘轮续调） |
| 左/低音方向手动按住 | `A1010100000002xx1F`，需持续刷新 |
| 右/高音方向手动按住 | `A1020100000002xx1F`，需持续刷新 |
| 停止 | `A10102000000011F` |
| 设置速度 | `A10801xx` |
| ESP32 编号初始化 | `A1F2hhhh`，`hhhh` 为非零递增 16 位编号 |
| ESP32 本地定时运动 | `A1F1ddhhhhpppprrrr`，详见主目录 `PROTOCOL.md` |
| 编号棘轮空回 | `A1F3hhhh`，仅真实高音修正到限位后许可 |

仅保留 BLE 调试工具发送大写文字停止：

```text
STOP
```

## 初始化逻辑

发送带编号初始化，例如 `A1F20001`（请求编号 1）后：

```text
1. 电机向低音/左方向连续转
2. 低音限位触发后立即停止
3. 等 200ms
4. 向高音/右方向反转 10 秒
5. 原限位已确认释放且未重触发才停止，通知 HOME_DONE:1
```

当前默认假设：

```text
60 rpm = 1 圈/秒
反向 10 圈 = 10 秒
```

后面实际测试后，可以改 `MOTOR_MS_PER_REV`。

## 安全逻辑

ESP32 本地负责真正的电机安全，不依赖手机实时反应：

- BLE 断开：控制循环本地停止电机，不依赖手机再发送 STOP
- 低音限位触发时，禁止继续向低音方向转
- 高音限位触发时，禁止继续向高音方向转
- 两个限位同时触发：认为接线/机构异常，立即停止并发送 `FAULT`
- 初始化寻找低音限位超过 `HOME_SEEK_TIMEOUT_MS`：停止并发送 `HOME_ABORT`
- 初始化反向回退时碰到高音限位：停止并发送 `HOME_ABORT`
- 初始化回退开始后，低音原限位超过 `piano::HomeReleaseGuard::ReleaseTimeoutMs`（暂定 2000ms）仍不释放，或释放后重新触发：停止，发送 `HOME_LOW_STUCK` 和 `HOME_ABORT`，不能发送 `HOME_DONE`
- 初始化速度为 0 时拒绝初始化，发送 `HOME_ABORT` / `FAULT`

固件已通过 Arduino-ESP32 3.3.8 的完整编译，实物联调尚未完成。2 秒释放超时须在空载实测后确认；不能为了消除报警直接放宽而不检查接线和机构。定时运动已由 ESP32 接管，APP 已切换为带编号的初始化及定时运动，两端软件构建和主机检查通过，但蓝牙运行时与实物验证仍未完成。空载测试清单见主目录 docs/SAFETY_VALIDATION.md。

`MotorSafetyCore.h` 的定时运动状态机（预加载、130ms 换向停顿、修正、停止）已接入 BLE 命令与 PWM 输出。回调仅入队，控制循环执行；断连/STOP 使旧会话/旧命令失效。手动按住需小于 750ms 刷新，连续最长 30 秒，过期或换向需 STOP 解锁。队列溢出、过期命令也会停止。`tools/test-motor-core.ps1` 将同一 C++ 核心编译为 WebAssembly 并运行主机模拟测试；这不是整份 ESP32 固件编译或实物验证。

新 APP 发送带编号的高级初始化命令（旧 APP 不兼容）：

```text
A1 F2 00 01
```

然后等待 ESP32 通知：

| 通知 | 含义 |
|---|---|
| `HOME_START:编号` | 初始化开始 |
| `HOME_LOW_LIMIT:编号` | 已碰到低音侧限位 |
| `HOME_BACKOFF:编号` | 正在反向回退 |
| `HOME_DONE:编号` | 初始化完成 |
| `HOME_ABORT:编号` | 初始化失败 |
| `FAULT` | 限位/接线/机构保护 |

## 棘轮扳手续调保护

只有高音修正阶段碰到高音限位（不是低音限位、预加载或两侧同时触发），才发送 `MOVE_HIGH:编号` 并允许一次 `A1F3` 回程请求。APP 必须先复测仍偏低；回程不参加音分经验学习，不是降音，也不是取下扳手的 `HOME`。

回程先停 130ms，再向低音限位运行。高音原限位须在 2 秒内释放，释放后重触发、两个限位冲突、120 秒超时、STOP 或断连均停止。低音限位小于暂定 1 秒即出现视为行程/接线异常。到低音限位后停止并通知 `RATCH_DONE:编号`，把该处当作零点；APP 再次确认琴音后才继续向高音侧定时调节。零点无低音预加载，再往高音移动还须确认低音限位释放。

同一次初始化最多 3 次回程，普通 STOP 不清零计数。棘轮拨片处于调高方向时，反转不能用于自动降低音高；音偏高应停机并人工检查。参数及空回是否完全不带动弦轴均须实物验证。

## 如果方向反了

先不要改接线，可以在固件里改这一行：

```cpp
static const bool INVERT_MOTOR_DIRECTION = false;
```

如果实际低音/高音方向反了，把它改成：

```cpp
static const bool INVERT_MOTOR_DIRECTION = true;
```

然后重新上传。

## 到货后的第一轮测试

1. 只接 ESP32，不接电机：确认手机能搜索到 `troy high school`
2. 接限位开关，不接电机：手按两个限位，看 APP Notify 和串口是否变化
3. 接电机驱动，不接电机：用万用表看 IN1/IN2 是否按命令变化
4. 接电机但不装扳手：用二进制手动按住命令测试两个方向及 `STOP`，确认刷新租约与 30 秒上限
5. 测初始化：低音方向转到限位，停，反向 10 秒
6. 如果方向反了，改 `INVERT_MOTOR_DIRECTION`
7. 如果 10 圈不等于 10 秒，修改 `MOTOR_MS_PER_REV`
